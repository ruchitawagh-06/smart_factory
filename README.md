## 🚀 How to Run Directly in GitHub (Zero Setup Required)

You can run this full-stack application **directly inside GitHub** in your web browser using **GitHub Codespaces**:

1. Open this repository on GitHub.
2. Click the green **`<> Code`** button near the top right.
3. Switch to the **Codespaces** tab.
4. Click **"Create codespace on main"**.
   - GitHub will launch a full cloud VS Code environment right in your browser!
5. In the built-in terminal at the bottom, type:
   ```bash
   npm install
   npm run dev
   ```
6. A notification will pop up in the bottom right corner:  
   *"Your application running on port 3000 is available."*  
   Click **"Open in Browser"**!

## 💻 How to Run Locally on Your Computer

If you have Node.js installed on your computer:

```bash
# 1. Clone this repository
git clone https://github.com/<your-username>/<your-repo-name>.git

# 2. Open the project folder
cd <your-repo-name>

# 3. Install all dependencies
npm install

# 4. Start the full-stack SCADA development server
npm run dev
```

Open your browser and navigate to:  
👉 **`http://localhost:3000`**

## 🏭 Core Features

- **Live Factory Floor Digital Twin:** Visual interactive zoning for Machining, Molding, Assembly, and Packaging.
- **Dynamic Telemetry Engine:** Real-time sensor streaming for Temperature, Vibration, Spindle RPM, Electrical Power, and Pressure.
- **Machine Inspection Modals:** Interactive schematics with operational telemetry gauges.
- **Automated Alarm & Diagnostics:** Threshold violation warnings with actionable mitigation advice.
- **Remote Supervisory Controls:** Safe Start / Stop controls with persistent status tracking.
- **Dark & Light Mode:** Industrial UI with high-contrast accessibility.
